# HydroPad

HydroPad is a macropad for people with palmer hyperhidrosis.
It has some holes for the water to go through.

## Required Components

- 1x PCB
- 1x Top Plate
- 1x Bottom Case

- 1x Seeed XIAO RP2040
- 6x through-hole 1N4148 Diodes
- 5x MX-Style switches
- 1x EC11 Rotary encoders
- 1x 0.91 inch OLED display
- 5x blank DSA keycaps
- 4x M3x5mx4mm heatset inserts
(I'll use my own screws instead of M3x16mm screws included in the kit)
